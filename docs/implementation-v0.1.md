# MomoPoseForge v0.1–v0.3 实现记录

首个可运行版本采用 React、TypeScript、Three.js 和本地静态资源，当前角色为用户指定的 Adobe Mixamo X Bot，保留红色外壳和深色机械关节。没有接入 AI 推理服务。

## 开发与验证

在仓库根目录执行 `npm install`，然后执行 `npm run dev`。开发地址为 `http://127.0.0.1:5173/`。

- `npm run build`：类型检查与静态生产构建，输出到 `dist/`。
- `npm test`：双骨 IK、投影坐标和工程文件校验测试。
- `node web/scripts/prepare-xbot.validate.mjs`：真实 GLB 加载、骨骼与蒙皮变形检查。
- `node web/scripts/verify-export.mjs <ZIP绝对路径>`：用工程重建骨骼，逐个相机独立复算 COCO18 坐标，并核对 PNG 尺寸。

人体为 28,374 顶点、49,112 三角面、68 根骨骼，原始高 1.7 米，Y 向上，初始面向 +Z。来源、许可和固定源版本见 `web/public/models/XBOT-ASSET.md`。重建脚本为 `web/scripts/prepare-xbot.mjs`。

## 当前能力

支持带肩髋限位的全身联动、手脚双骨 IK、肘膝极向控制、骨盆平移、胸腔目标、关节旋转、手脚位置和方向固定、镜像与单侧复制、三种手型及逐节手指精调、前臂翻转、前脚掌弯曲、18 个预设、100 步姿态历史，以及本地草稿、收藏和工程文件。

移动与旋转有明确文字标签，选择不同部位时切换到对应的默认模式。左键摆姿，右键旋转视角，中键平移，滚轮缩放。胸腔移动保留局部转身角；脊柱与头颈按静止姿态实施摆动锥和轴向扭转限位，单次拖动以起始姿态为基准。编辑相机不随每次姿态提交自动变焦，五视图导出范围另行更新。

同类工具和后续全身 IK 评估顺序见[参考说明](reference-tools-and-controls.md)。本轮增加实际 PoseEngine 的连续拖动、模式切换、可达目标、路径一致性、固定点与工程恢复测试，不以四肢测试结果代替全身稳定性结论。

2026 年 10 月 29 日本轮验证：46 项自动测试通过；浏览器实测胸腔边界拖动、头部角度输入、头部切回手脚、撤销与重做。新的五视图验证包包含 19 个文件、每视图 768 × 1024，独立重投影的最大关键点误差为 0.000495 像素。三个宽度的界面检查为 0 FAIL、1 个紧凑文字警告；尚未进行帧率或完整全身 IK 性能验收。

五个相机默认是正面、斜侧、侧面、俯视、仰视，可以用当前观察替换任一槽位。出图使用统一中心和正交尺度，图片、骨架图和二维关节点取自同一姿态快照。ZIP 包包含按勾选项生成的 PNG、COCO18 JSON、工程文件和相机 manifest。

本地数据保存在用户浏览器；清理浏览器数据会清除草稿和收藏。工程 JSON 可下载备份。

## 仍需后续完善

当前身体约束不包含全身碰撞、重心平衡或物理接触求解。IK 与 FK 肘膝共同使用对照 X Bot 原始动画确认的单向铰链轴，IK 同时对齐骨段和关节弯曲平面；测试覆盖 18 个预设的 72 条链与连续拖动。前臂另外允许轴向翻转，膝盖保持单向铰链；肩髋的复杂生理摆动与扭转限位还需继续校准。手指逐节 FK 有屈曲及根部张开范围；并非手指 IK，也不处理手指与身体碰撞。

保留 COCO18 图片与 JSON 兼容文件，头部采用绑定到头骨的虚拟锚点。v0.2 另提供身体与双手各 21 点的输出、深度和法线图，完整面部点集尚未实现。已完成一个固定 ControlNet 工作流的本地实际生成验收，不能据此宣称所有 AI 都已兼容。

锁定五视图构图、相机槽位重命名、复杂骨骼导入及图形上下文丢失后的自动重建尚未实现。首版只用固定人体比例，手机以查看为主。

## 界面设计

采用前端设计技能的 True-black flat 方向，seed 551187941，无重抽。以大型三维视口回答“当前姿势是否合适”，灰阶工作台减少干扰，骨架控制点作为少量强调色，五张真实渲染预览是产品的主要识别元素。字体 Inter 本地打包。

桌面、平板、手机的浏览器检查以 1440、768、390 像素执行。工具栏采用桌面创作工具的紧凑密度，元信息 11 至 12 像素；三维视口不是统计图表，因此不按图表主色占比添加装饰色。

## X Bot 工程版本

当前骨骼配置为 mixamo-xbot-v2，声明左右手肘和双膝的实际局部弯曲轴，防止旧的无铰链姿态覆盖修复后的状态。原 MakeHuman 和 X Bot v1 的本地草稿与收藏保留在各自版本的存储项中；当前版本不会覆盖它们。工程导入会校验骨骼版本。

## 右键飞行镜头

在三维视口按住右键，鼠标控制朝向，W/S 沿镜头朝向前进或后退，A/D 横移，Q 沿世界竖轴下移、E 上移，Shift 以三倍速度移动。升降不随镜头俯仰改变，组合移动键仍保持相同速度，Q/E 同时按下相互抵消。松开右键或移动键立即停止；窗口失焦、页面隐藏、取消指针捕获或按 Esc 也会退出。退出后 W/E 恢复姿态编辑快捷键，F 聚焦人物，中键仍用于平移。

Q/E 补充验收：182 项前端测试通过，覆盖升降、对向抵消、三轴组合速度、Shift、观察锁、输入框与失焦停止。浏览器实按右键组合 E/Q，工程比对分别上移约 0.611 米、下移约 0.607 米，X/Z 不变、人体与固定点完全相同；相机四元数最大分量差约 1.39e-17。松开右键后 W/E 恢复工具切换且不移动镜头，记录见 validation/qe-camera-browser.json。

导航时暂时停用关节操纵器，不写入姿态历史，也不修改人体或五视图相机。正交视图进入飞行时转换为透视相机并保留目标平面的取景；“当前视角”导出保留实际相机位置和朝向，按输出宽高比适配，五视图仍使用统一正交构图。

本轮共 56 项测试通过，新增验证导航输入生命周期、失焦停止、方向和速度、正交转换及相机导出。浏览器实测前进、后退、横移及正交视图进入导航；飞行前后的工程内容完全相同，导出记录的相机实际移动约 0.365 米。当前视角和五视图导出的关节点均通过独立重投影检查。

## 全身与手指控制开放（2026-10-29）

模型保持 68 根骨骼，开放 53 个可选择部位：23 个身体部位和双手共 30 节指骨。其余包含指尖等末端节点，不作为独立旋转关节。全身控制点默认显示；手部近景只显示当前一只手的 15 个指骨控制点，避免身体控制点遮挡手指。肩、上臂、髋、腰、颈和脚趾可在视口或部位列表选择，默认进入相应操作模式。

“手指精调”支持左右手切换、五指选择、每指三节弯曲、根部张开、聚焦手部与返回全身。滑杆拖动预览只在松开时提交一次历史；键盘调整也可撤销。手型预设仍能恢复整只手，手动修改后标记为自定义。模型中脚趾只有每侧一个 ToeBase，因此“脚趾控制”实际调整整个前脚掌，范围为 -45° 至 65°，不支持五个脚趾独立控制。

前臂翻转范围为 ±90°。弯肘和轴向翻转分开求解，翻转不挪动腕关节；之后移动手部 IK 仍保留翻转角。固定手掌方向时，由手腕关节补偿以保持固定方向。一次测试发现绑定轴并非完全正交，简单扭转投影会在反复 IK 中累积误差，已改用子骨骼方向求弯曲后再分解轴向翻转。

角度范围是本模型的保守编辑范围，尚未经生理活动范围标定。全部修改写入现有工程的骨骼四元数，支持草稿、撤销、镜像、单侧复制和工程恢复，保持 mixamo-xbot-v2 格式。素体图片反映手指姿态；COCO18 骨架图和关键点 JSON 仍只有身体 18 点，未新增手指 21 点输出。

本轮验收：67 项自动测试通过，生产构建通过。新增 11 项覆盖双手全部 30 节指骨限位、骨长、前臂翻转后的 100 步连续 IK、反关节约束、固定方向、脚趾、镜像与工程往返；真实 GLB 顶点检查确认手指/前脚掌蒙皮变形及工程恢复。浏览器检查滑杆拖动一步撤销/重做、另一侧拇指、翻转和脚趾端点、全身选择与导出工程重新打开。五视图包为 19 个文件，768 × 1024，COCO18 独立重投影最大误差 0.000494 像素；手部近景“当前视角”包为 7 个文件，最大误差 0.000381 像素。

1440、768、390 像素界面检查无横向溢出。属性区内容增加，需要纵向滚动；紧凑文字仍是已知可读性限制。全身 IK 参考求解器的固定条件评估见[参考说明](reference-tools-and-controls.md#全身-ik-对照评估2026-10-29)，本轮没有替换生产求解器。

## 肩髋限位与受约束全身联动（2026-10-29 后续轮次）

右侧“全身联动”默认开启；“固定双脚”把两脚当前位置和方向一起固定，之后可用“释放双脚”解除。移动骨盆或胸腔时，腿和脊柱可以配合；手脚目标超出单条肢体的范围时，肩、躯干及骨盆参与。开启地面约束后，移动开始时接近参考地面的脚也作为临时支撑，不会自动写入永久固定点。关闭联动后恢复独立四肢/躯干操作，关节范围约束仍生效。

新增 `limbLimits.ts`，将锁骨、上臂、髋的摆动与轴向扭转分开约束。范围相对本模型 T 姿态，屈伸与侧向采用联合椭圆范围，不允许两者同时达到各自极限；FK 输入、IK、旧工程恢复使用同一实现。数值是保守编辑默认值，仍需继续做人体活动范围标定。

`fullBodyIK.ts` 在原双骨 IK 基础上执行带阻尼的多目标最小二乘，用投影后的关节微扰计算有效 Jacobian，每个试探步骤都执行关节限位和回溯检查。整体步长统一缩放，保留支撑腿对骨盆移动的补偿关系。接近直膝时，先投影骨盆到支撑腿可达范围并生成解析屈膝初始解，避免直腿状态的奇异点。

固定点及地面高度优先于正在拖动的目标。若仍无法同时满足，沿本次拖动的起始姿态回退至可行位置并提示剩余距离；判定容差为 1.5 毫米。已有不可行固定点不会被宣称已修好，界面会显示误差。躯干位置编辑保留开始时的脊柱转身角；前臂翻转角、固定手脚方向继续保持。手脚自动够取时，单次交互的骨盆位移最多 0.35 米，不会无限跟随极远目标。

`fullBody` 作为可选布尔字段保存在 v1 工程中，旧工程缺少该字段时默认开启。骨骼版本、模型、骨长不变，原始文件不会被覆盖；导入旧姿态时会投影超出新肩髋范围的关节。开关、双脚固定和联动姿态都支持撤销/重做。数值旋转固定手掌时会更新固定方向，重置肩部也执行固定点检查。深蹲、行走、侧身回头预设已按新限位校准。

本轮验证共 **110 项测试通过**，生产构建通过。新增 43 项覆盖六个肩髋关节的极端输入、全部 18 个预设的限位/骨长/末端精度、固定脚下的骨盆与胸腔联动、左右够取、四个固定末端、FK 极限、镜像、前臂翻转、工程开关，以及蹲、跪、弓步、抬手、前倾坐中的连续胸腔调整。全部预设的末端目标误差低于 5 毫米，本次实测最大 1.431 毫米。

100 步手部目标轨迹从 [0.235, 0.93, 0.02] 线性移动至 [0.855, 1.58, 0.25]，每步使用同一拖动起始姿态、固定双脚。最大固定点误差约 0.000009 毫米，最终手部误差约 0.00111 毫米；最大单步关节变化 10.754°、骨盆变化 12.489 毫米。这条路径未出现大幅翻转，但不能据此保证所有路径同样平顺。Node v24.13.1 本次 CPU 控制路径采样中位 0.158 毫秒、p95 2.522 毫秒、最大 3.834 毫秒；不包含 WebGL、蒙皮包围盒、预览与图片生成，不代表浏览器帧率。运行 `npm test -- fullBody.test.ts` 会生成本次采样的 `artifacts/fullbody-evaluation.json`。

浏览器实测真实鼠标骨盆下沉约 0.32 米、一步撤销/重做、肩部超限输入、远处手部目标、工程保存/回读，以及手机属性面板。五视图导出包为 19 个文件、768 × 1024；从真实 GLB 独立重建后，关键点重投影误差小于 0.000499 像素，两个固定脚的位置误差约 0.000009 毫米、方向误差为 0。1440、768、390 像素检查为 0 FAIL、2 WARN；小字号及需纵向滚动的属性面板仍是已知界面限制。

当前实现提供受约束的身体联动，不处理全身碰撞、重心平衡、物理支撑力或手指 IK。地面仍按脚踝参考高度判断，不计算完整脚底接触面；极端脚掌或脚趾旋转仍可能穿地。数值迭代也不保证对所有复杂、相互冲突的目标找到全局最优解。

## v0.2：手部、深度、法线与下游工作流

已实现双手各 21 点的 OpenPose JSON 与身体/双手合并骨架图，并保留旧 COCO18 文件；另提供米制三维骨架。手部遮挡可开关，使用同一相机的 24 位深度缓冲判断，并为位于自身表面内的骨骼中心保留距离容差。

深度为相机轴向距离线性归一化，近白远黑，五视图共用范围。法线采用 ControlNet 1.1 / ScanNet 可视化约定，数据通道不经过灯光、色调映射或 sRGB 数值转换；同时提供角色遮罩。相机、深度范围、方向和点序全部记录于 manifest。独立校验脚本用真实 GLB 的变形顶点、插值蒙皮法线和 CPU 射线复算 GPU 输出，而不是只检查文件名和尺寸。

导出面板增加素体/骨架/深度/法线预览，窗口尺寸改变后重建预览；内容区独立滚动，下载操作固定可见。导出冻结姿态和相机，支持取消；异常路径恢复主视口的材质、背景、渲染目标和色调映射。新 ZIP 附带固定模型版本、权重与种子的工作流配置，以及运行脚本、依赖和模型清单；网站仍不执行 AI 推理。

本轮 119 项前端测试、8 项 Python 文件契约测试通过，生产构建通过。五个正交视角抽样 439 个真实表面像素，深度最大误差 0.534 字节，法线最大误差 0.553 字节，手部投影误差小于 0.000500 像素；透视手部近景另外抽样 156 个表面像素，误差同样小于一个字节。两组几何复核的手部遮挡不一致数均为 0。手机与平板导出面板、通道切换和大尺寸取消已实测；界面检查维持 0 FAIL、2 个紧凑字号/纵向滚动警告。

本机 RTX 4070 已实际运行全身挥手、手部指向两组默认工作流，每组比较骨架、骨架+深度、骨架+深度+法线，均为同种子、24 步、384×512。完整导出包中的脚本也已从独立解压目录运行，其三通道输出 PNG 与仓库脚本结果哈希相同。精确配置、生成耗时、显存、输入哈希、图像和可重放 ZIP 见[AI 导出验收](ai-export-workflow.md)。结果展示结构约束的实际效果，也保留了多指、手掌解剖和模型几何带来的局限。

## v0.3：相机、画幅与五视图构图

新增“相机与画幅”面板，保持既有 True-black flat 方向与 seed 551187941，无重抽。观察相机锁暂停右键飞行、中键平移、滚轮缩放、聚焦和视角切换，人体控制保持可用。透视 FOV 支持 15°–100°；透视/正交转换保留目标平面取景。最多 12 个命名书签保存位置、目标、四元数、up、FOV、正交尺度、zoom 和裁剪平面，支持恢复、改名、同名更新与删除。

五视图可命名，并独立锁定共用中心和垂直尺度；普通姿态提交、加载预设不自动改写锁定构图。边界提示根据人物世界包围盒保守判断，因此称“可能超出画幅”，不是逐像素裁切证明。显式“重新适配五视图”会更新构图并保持锁定。窗口 resize 保留观察正交相机自己的尺度/zoom，不再误用五视图尺度。

模块导入不安装浏览器监听。服务跟随系统减少动态效果偏好，支持取消已有动画；工作台拥有的服务随工作台释放，外部注入的服务由调用方管理。通用 disclosure 可同步关闭内容的 inert 状态，不修改产品的展开存储。

框架 44 项测试、PoseForge 241 项测试及构建通过；TextureForge 579 项通过、6 项跳过，定义校验和离线/静态构建通过。真实浏览器动效回归 14 项通过，含默认工作台的原生 200ms 布局过渡、减少动态效果、重入取消、展开交互、重排预览、卸载和参数不变。两产品实际弹窗均使用共享 120ms 淡入，TextureForge 属性展开过渡为 160ms，关闭后内容 inert；未观察到控制台错误。

## 多骨架工作流基础（2026-10-30）

姿势库新增“当前骨架”选择。`rigs.ts` 登记稳定 id、版本、单位/方向、根骨、资产及静止层级、可编辑关节、链、镜像配对、接触点、策略、限位、能力与预设。当前提供 X Bot（原人体 IK 策略）与 16 关节基础人形（程序生成、FK 策略）；后者有不同骨名与层级，无手指、IK 或 OpenPose 能力。它用于验证和使用基础关节工作流，不代表已经交付动物或任意模型自动绑定。

切换候选在独立的隐藏视口容器中完成资产加载、工程校验和首次渲染，成功后才替换原角色。开始切换会取消拖动并停止飞行相机；失败保留原角色，连续切换只接受最新请求。停用的视口、监听、动画帧、几何、材质、纹理、骨骼纹理、阴影贴图及 WebGL 上下文随实例释放。X Bot 的 IK、限位、五指及人体关键点仍是明确的人体专用策略；通用 FK 路径没有四肢数量或五指要求。

各骨架及版本保存独立草稿、收藏、选中关节、预设和会话撤销/重做；相机、画幅、五视图方向、参考图和道具是场景数据，切换后继续使用当前场景。恢复角色历史时把场景重新建立为当前基线，不用旧历史恢复另一骨架使用期间的旧场景。刷新保留最后选择的骨架与草稿，撤销栈仍为会话内数据。旧 X Bot 草稿、收藏和手势库通过旧键回读，旧 v1 工程缺少 `rigVersion` 时按 X Bot v1 解释；缺失骨架或不兼容版本明确拒绝。打开不同骨架的工程会先准备目标骨架，全部校验成功后才打开。

按能力隐藏手势、手指精调、全身联动、固定点、对称和道具接触定位。通用骨架可导出 `skeleton.png`、`joints.json` 与 `skeleton-world.json`（实际父子连接、关节名及米制坐标），不输出伪造的 COCO18/HAND21 或人体姿势工作流。素体、五视图、深度、法线、mask 和工程继续可用。X Bot 的原人体输出保持兼容。

验证：253 项测试及生产构建通过，新增 12 项覆盖可变拓扑、三节非人形关节链、单轴肘膝限位、跨骨架拒绝、版本/存储隔离、旧手势库、切回恢复、共享场景、失败候选清理、过期请求、取消与共享资源释放。基础人形弯肘超过 90° 使用单轴角度，反复恢复不累积旋转误差。

真实浏览器验证 X Bot 抬手和头部 25°、基础人形肘部 -60° 来回恢复；两者撤销/重做独立。另一骨架添加的方块在切换和旧角色撤销后仍保留。连续切换后只保留 1 个运行容器及 1 张视口 canvas；基础人形不显示手势或 IK 控制，-120° 弯肘可正确显示。缺失骨架工程被拒绝并保留原姿势，缺少新字段的旧 X Bot 工程可自动切换后打开。

浏览器实际导出并解包：基础人形五视图 ZIP 包含 16 个有效投影关节、真实连接的骨架图及非空深度/法线/mask，没有 OpenPose/COCO18/人体工作流文件。X Bot 导出仍含身体 54 个坐标数值与左右手各 63 个数值，68 根骨骼；旧工程重开后相对原关节数据最大差为 2.22e-16。在 1280、960 和 390 像素宽度检查了切换入口，页面无横向溢出；390 宽度下可从移动导航打开姿势库并选择骨架。截图与本机检查报告位于忽略提交的 `artifacts/rig-*`。


## 首个动物骨架：Fox 小狐狸 FK（2026-10-30）

正式选择器中的基础测试人形替换为带纹理和蒙皮的 Fox 小狐狸；原基础人形定义保留，旧工程打开时临时显示其选项。Fox 包含 24 个蒙皮关节，其中 22 个提供控制，两个坐标基座保留在真实骨架数据中。头颈、脊柱、四肢和三节尾巴支持逐关节旋转，根部可移动；没有四足 IK、脚掌固定、地面约束或人体 OpenPose。原始 Survey、Walk、Run 动画保留在资产，尚未提供播放取姿。

资产固定来自 Khronos glTF Sample Assets 提交 `4995a638c96dbc94376d3d6164e70fee3ac7f7a2`。保留原 GLB、许可、作者和元数据；离线脚本 `tools/prepare-fox.mjs` 校验源 SHA256，将顶点、节点位移、逆绑定矩阵平移和动画平移统一按 0.01 归一化为米制编辑尺寸，保持旋转、拓扑、纹理与材质。转换文件与源文件哈希分别记录，运行与构建不依赖外部 CDN。导出 ZIP 的 `ASSET-CREDITS.txt` 和 manifest 包含作者、来源、许可链接及改动说明。

Fox 静止旋转不是单位四元数，因此通用 FK 的角度、操纵器和限位改为相对于各关节静止姿态计算，再乘回静止旋转；不把骨架强行拉直或套用人体骨名。单轴肘、膝和跗关节使用自己的轴和范围，头颈、脊柱及尾巴使用独立编辑限位。旧基础人形的静止旋转为单位值，继续兼容；X Bot 使用原人体策略。通用文案改为“角色”，帮助按能力显示。

实际导出发现原 Fox 资产缺少顶点 NORMAL，标准素体可借助平面着色显示，但覆盖材质的法线图会全黑。现在加载时仅对缺失法线的几何生成顶点法线，保留已有法线；浏览器再次导出的法线图恢复有效颜色，斜侧视角法线前景与 mask 均为 111520 像素。

验证：265 项测试和生产构建通过。本轮新增 12 项，实际解析 GLB 骨架、蒙皮与动画（Node 测试仅替代纹理解码，真实纹理在浏览器检查），验证固定哈希、0.01 转换、24 关节、1728 顶点、动画及纹理保留、法线补齐、相对旋转、肘膝限位、操纵器重复事件、平移、工程往返与旧 X Bot 资产版本兼容。静止蒙皮抽样的最大位置误差约 1.12e-7 米。

浏览器验证头部 20°、尾巴 40°；切到 X Bot 再返回后保留姿势、选择与收藏，撤销尾巴至 35°后可重做。人体保留手势及原控制面板，小狐狸不出现手势或人体 IK。狐狸导出工程重新打开、刷新恢复及旧基础人形工程打开均通过，工程关节数据往返最大差为 0；每次完成切换后只保留一个视口实例。实际五视图 ZIP 含 36 个文件，24 关节共 120 个有效投影全部命中骨架图标记，独立重投影最大误差约 1.61e-13 像素。素体、骨架、深度、法线、mask 和工程有效，附带署名文件，没有人体 OpenPose/COCO18 或人体工作流。1280、960、390 像素宽度下切换入口可用、页面无横向溢出，中英文骨架和关节标签可切换。截图与本机检查位于忽略提交的 `artifacts/fox-*`。


## Fox 四爪 IK 与固定支撑（2026-10-30）

Fox 以独立 articulated 策略接入位置 IK，仍保留头颈、脊柱、尾巴和各关节的 FK 精调。前腿为两段、后腿为三段骨链，链长、关节名、可动轴、静止旋转和限位均来自骨架定义；复用现有受约束阻尼最小二乘求解器，不把后腿截成人体两段链。默认首次选择左前爪，右侧另提供四爪快捷入口；选中爪子后以 W 移动，其他身体关节以 E 旋转。

固定点支持逐爪或全部固定位置，可额外固定方向。手动移动或旋转根部时，腿部优先补偿固定点；若受骨长、关节范围或固定朝向约束无法完成，就从拖动起点向目标回退，保留可行身体位移并提示。实际拖动始终从 pointer-down 姿态计算，不累计上一次事件的误差；取消可恢复整次动作，撤销/重做保留当前选中部位。没有自动全身够取、地面高度限制或真实脚底接触，狐狸也不显示人体手势、人体道具接触定位或 OpenPose 选项。

骨架资产版本不变，新控制状态增加 `ikVersion: 1`。旧 Fox FK 工程和收藏的空 IK 控制字典会保持原关节姿态，并在载入后从实际骨架派生四个目标；不会套中立姿态或复制另一骨架的控制数据。新文件缺少目标或控制版本不兼容时明确拒绝。固定点、目标、选中部位和历史继续按骨架隔离，切回后恢复。

验证：282 项测试及生产构建通过，本轮新增 17 项覆盖不同链长、单链配置、抬爪、跨过伸直区间、持续侧移、不可达目标、四爪支撑、方向固定、极端身体位移回退、更新锚点、FK/IK 并用、取消、重复拖动、整体旋转平移与旧工程迁移。前后腿限位和骨段长度在压力路径中保持有效。

真实浏览器使用移动轴拖动左前爪，关节点 Y 从约 0.067 米升到 0.178 米；一次撤销恢复到 0.067，重做恢复到 0.178，选中爪子不跳变。固定四爪后实际下拖根部约 6.2 厘米，独立重建导出骨架所得最大固定点误差约 0.007 毫米，非根骨局部位置变化为 0，相机数据不变。切到 X Bot 后仍有手势和双脚固定，切回 Fox 后四个固定点及 IK 姿势保留，撤销/重做独立，视口 canvas 数量为 1。

旧 FK 工程在浏览器重新打开后，关节数据最大差为 0，新增四个 IK 目标。包含四爪固定与下蹲姿态的实际五视图 ZIP 为 36 个文件、1024×1024；24 个关节共 120 个有效投影全部命中骨架图，独立重投影最大误差约 1.61e-13 像素，斜侧深度/法线/mask 前景同为 103146 像素。工程保留 `ikVersion`、四个目标和四个固定点；署名文件继续提供，没有人体 OpenPose/COCO18 文件。本机截图、工程与检查报告位于忽略提交的 `artifacts/fox-ik-*`。
