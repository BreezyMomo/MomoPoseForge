# 常见问题

[简体中文](faq.md) · [English](faq.en.md)

[手册目录](README.md) · [开发与部署](development.md)

## 手脚拖不动

检查当前角色是否隐藏或锁定、是否仍处于动画预览、是否选了**整体位置**，以及末端是否已固定。先捕获/取消动画、切回**关节摆姿**、解除需要重新定位的固定点，再选择正确部位。FK 部位通常需要旋转，不是任意平移。

## IK 会比 FK 更高级吗

IK 适合确定手脚目标，FK 适合逐关节控制。摆姿通常组合使用；头部、尾巴与手指的直接旋转仍很有用。具体可用能力由骨架决定。

## 为什么膝盖或肘部朝向不对

先确认目标在可达范围内，再用**肘膝朝向**调整弯曲方向。完全伸直时先略微弯曲。不要用整体旋转替代关节控制。问题仍存在时，保存能复现的最小工程，并记录骨架、部位及操作步骤。

## 狐狸为什么没有某个人体选项

狐狸是四足骨架，只提供实际适配的四爪 IK、固定及 FK。它没有人体手势、人体 OpenPose、人体全身联动或 X Bot 脚底支撑。BodyChan / BodyKun 同样不自动具有全部 Mixamo 人体功能。

## 换骨架和换皮肤有什么区别

换骨架更换当前实例的身体结构与控制能力；换外观沿用同一骨架，更换完整表面和服装。导入的角色必须兼容当前骨架，不是任意模型自动绑定。

## 导入 FBX / GLB 失败

先确认入口是外观还是动画。外观须已蒙皮、贴图内嵌并匹配当前骨架；外部动作需要受支持的人体层级和实际动画片段。只有网格、外部贴图引用、不同骨架或未接入的 VRM / BVH 不会自动转换。失败时保留原场景，可按错误提示检查源文件。

## 暂停动画后为什么又回去了

暂停仍是预览。请点捕获当前帧的按钮，提交成可编辑姿势，再切换角色或骨架。取消预览则恢复进入前的姿势。

## 五视图不是我要的正上方

默认斜俯视和斜仰视带倾角。在**相机与画幅**把槽位改为顶视或底视；输出仍保留五个槽位。若角色出框，检查构图锁并重新适配。

## 导出的 OpenPose 为什么没有狐狸或绘画素体

人体 OpenPose 目前只对 X Bot / Y Bot 提供。其他骨架使用通用关节 JSON 或组合骨架图；它们不会被错误编码成人体。导出时隐藏的角色也会被排除。

## 其他电脑打不开外观，或收藏不见了

浏览器站点数据不跨电脑、端口和地址共享。轻量 JSON 只保存引用；跨设备用完整 `.poseforge`。完整包需要目标应用支持对应骨架版本。

## 在线版有账号、云同步或内置 AI 吗

目前没有。编辑和导出在浏览器中进行，AI 控制图供外部工具使用；ComfyUI 直接集成仍待开发。

## 页面空白、模型没加载或操作很卡

先确认浏览器 WebGL2 可用，并检查网络是否成功载入页面脚本和模型。减少角色数量、隐藏不必要角色或降低预览/导出尺寸。静态部署到子目录时，应使用正确的 Pages 构建，见[部署说明](development.md)。

## 本地提示无法解析 @momo/workbench/appearance

停止开发服务，在项目根目录运行 `npm ci`，再运行 `npm run dev`。保留仓库中的 `vendor/`、`package.json` 和 `package-lock.json`，不要复用另一台电脑的 `node_modules/`，也不需要克隆其他产品仓库。`npm run check:setup` 可检查安装状态；如果 `npm ci` 本身失败，保留它的完整日志排查。
